# Анимация облёта ЖК дроном

CSS/SVG-анимация: дрон влетает в кадр по дуге, облетает жилой комплекс и
зависает у фасада, после чего появляется заголовок. Формат вертикальный
(9:16), подходит для Reels / Stories / веб-баннера.

## Запуск

Откройте `index.html` в браузере — анимация запускается автоматически
(длительность сцены ~9 секунд).

## Что внутри

- `index.html` — сцена целиком: фон, дрон и заголовок с анимациями на CSS.
- `assets/building.jpg` — фото ЖК (фон сцены).

## Как заменить

- **Фото ЖК** — замените файл `assets/building.jpg` (кадрирование задаётся
  в `.building-bg` через `background-position`).
- **Дрон** — нарисован инлайн-SVG в стиле DJI Mini (корпус, лучи, подвес
  камеры, вращающиеся винты). Правится прямо в разметке блока `.drone`.
- **Текст** — блок `.title-container` (заголовок и подзаголовок).
- **Тайминги** — переменные `--duration` и `--ease-custom` в `:root`,
  ключевые кадры `@keyframes drone-flight` и `building-action`.

## Доступность

Учитывается `prefers-reduced-motion: reduce` — при включённом в системе
уменьшении движения анимация не проигрывается, сразу показывается финальный
кадр.
